# FakeStore API Testing Project

## Objective
To test FakeStore APIs using Postman and validate functionality, performance, and response behavior.

## APIs Tested
- Product List API
- Single Product API
- Login API
- Negative Login API
- Users API
- Get Cart API
- Create Cart API
- Update Cart API
- Delete Cart API

## Testing Performed
- CRUD Testing
- Authentication Testing
- Negative Testing
- Response Validation
- Status Code Validation

## Additional Testing
- Functional Collection Run Testing
- Performance Testing using Postman Runner
- Verified response time under concurrent users
- Newman CLI Automation Testing

- Total Requests: 9
- Assertions: 28
- Failures: 0
- Average Response Time: ~350ms
