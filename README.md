## Objective
To test FakeStore APIs using Postman.

## APIs Tested
- Product List API
- Single Product API
- Login API
- Negative Login API
- Users API
- Get Cart API
- Create Cart API
- Update Cart API
- Delete Cart API

## Testing Performed
- CRUD Testing
- Authentication Testing
- Negative Testing
- Response Validation
- Status Code Validation

- JavaScript
- JSON
